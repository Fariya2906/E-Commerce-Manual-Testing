# E-Commerce Website – Manual Testing

## QA Testing Project — Fariya

A structured manual testing project for an e-commerce web application covering requirements analysis, test planning, test scenarios, test cases, test execution, defect reporting, Jira defect tracking, and requirement traceability.

### Testing Scope

Registration • Login • Product Search • Product Details • Cart • Checkout • Payment • Order Confirmation

### Testing Techniques

Manual Testing • Functional Testing • Positive/Negative Testing • Equivalence Partitioning • Boundary Value Analysis • Decision Table Testing • Defect Reporting • Jira • RTM

### Project Workflow

Requirements → Test Plan → Test Scenarios → Test Cases → Test Execution → Bug Reports → Jira Tracking → RTM → Test Evidence
